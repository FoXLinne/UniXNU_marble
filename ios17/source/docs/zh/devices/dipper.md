# 小米 8（dipper）

小米 8（dipper） 是搭载 SDM845 的设备。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-dipper](https://github.com/hanyaa380/UniXNU-dipper) | [hanyaa380](https://github.com/hanyaa380) |

## 状态

UEFI 固件、启动镜像、UniXNU 菜单、负载 FAT 和合成 DarwinBoot 交接已在真机工作。公开的 fajita 内核到达 BSD init；它没有 NativeUfs，根设备等待不会结束。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。

# Unisoc UMS512 / T610YP

Unisoc UMS512 / T610YP 是搭载 UMS512 的设备。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-t610yp](https://github.com/hxzbaka/UniXNU-t610yp) | [hxzbaka](https://github.com/hxzbaka) |

## 状态

首次启动设备仓库。提供板级描述、源码内核配置和 ADT 生成器；UEFI 侧是外部 `edk2-sprd` 树。未记录真机结果。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。

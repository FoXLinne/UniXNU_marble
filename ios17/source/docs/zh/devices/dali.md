# Redmi K80 Ultra（dali）

Redmi K80 Ultra（dali） 是搭载 MT6991 的设备。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-Dali](https://github.com/localhosts-A/UniXNU-Dali) | [localhosts-A](https://github.com/localhosts-A) |
| [UEFI-Dali](https://github.com/localhosts-A/UEFI-Dali) | [localhosts-A](https://github.com/localhosts-A) |

## 状态

当前目标是通过 UniXNU 和 DarwinBoot 到达单核 XNU 早期启动检查点。存储、根卷和 iOS 用户态不在当前阶段。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。

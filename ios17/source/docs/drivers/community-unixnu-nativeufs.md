# unixnu-nativeufs

SM7325 UFS, SMMU and root storage support for the Samsung Galaxy Tab S7 FE Wi-Fi (SM-T733).

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [unixnu-nativeufs](https://github.com/RigoLigoRLC/unixnu-nativeufs) | [RigoLigoRLC](https://github.com/RigoLigoRLC) | SM7325 UFS, SMMU and root storage support for the Samsung Galaxy Tab S7 FE Wi-Fi (SM-T733). |

## State

Controller selection, GCC diagnostics and configurable SMMU addressing are implemented. The firmware-to-XNU handoff still requires device execution.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the driver and its state; it does not take over maintenance.

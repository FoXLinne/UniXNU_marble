# ArmVirtPlatform

ARM virtual platform for QEMU. Publishes the QEMU virt platform devices.

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [ArmVirtPlatform](https://github.com/UniXNU/ArmVirtPlatform) | [UniXNU](https://github.com/UniXNU) | ARM virtual platform for QEMU. Publishes the QEMU virt platform devices. |

## State

Used by the QEMU port.

## Build

Select the QEMU platform component and its kernel configuration. Its recipe builds `build/armvirt-platform/libArmVirtPlatform.a`. Follow [QEMU testing](/reference/qemu) for the virtual hardware and entry fixture.

# Meizu 20 Classic (m2381)

A community port for SM8550, maintained by RiverKawa271828.

- [RiverKawa271828/ios-m2381-unixnu](https://github.com/RiverKawa271828/ios-m2381-unixnu)

## State

The `m2381` branch contains the device tree under `devices/m2381/unixnu-m2381/` and firmware integration under `devices/m2381/uefi/`. Kernel, prelink and payload bring-up are in progress.

Use the current state and CI records to select the donor ABI and matching payload inputs. Follow the device branch selected by those records when running its CI workflow.

## Use this port

1. Read the pinned source and validation records below. Prepare the required firmware and system inputs.
2. Clone the device repository and follow its build guide from the checkout:

```sh
git clone --branch m2381 https://github.com/RiverKawa271828/ios-m2381-unixnu.git
cd ios-m2381-unixnu
git checkout 5886f365d16ab442c0f6210cfdf59ad9bb6a0ab0
git submodule update --init --recursive
```

3. Complete the build for that revision, follow the [bring-up order](/porting/bring-up), and use [log capture](/porting/log-capture) to record the last confirmed stage.
4. Save results in the [porting record](/porting/records). See [Port a device](/porting/steps) for board structure and component selection.

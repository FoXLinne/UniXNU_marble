# Nubia RedMagic 8 Pro / 8 Pro+ (nx729j)

nx729j is the Nubia RedMagic 8 Pro and 8 Pro+ with the SM8550 SoC. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer |
| --- | --- |
| [UniXNU-nx729j](https://github.com/2713385115/UniXNU-nx729j) | [2713385115](https://github.com/2713385115) |

## State

The firmware boots through SEC, PEI, DXE and BDS on a RedMagic 8 Pro+ and displays firmware logs. Board measurements, the ADT and firmware image checks are recorded.

The device source includes NativeUfs, SMMU and verified-root integration. XNU, storage-root and userland results need a matching kernel and device run record.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.

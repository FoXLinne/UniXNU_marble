# Benesse TAB-A04-BR3 (a04br3)

a04br3 is the Benesse TAB-A04-BR3 tablet with the MediaTek MT8167 SoC, four Cortex-A35 cores, GIC-400, 2 GiB DRAM and eMMC. The port below is an independent community project. The UniXNU organization does not maintain it.

| [uefi-a04br3](https://github.com/mouseos/uefi-a04br3) | [mouseos](https://github.com/mouseos) |
| [NativeMsdc](https://github.com/mouseos/NativeMsdc) | [mouseos](https://github.com/mouseos) |

## State

The tablet reaches the iPadOS home screen on four CPUs with eMMC DMA and CPU framebuffer rendering. PowerVR Vulkan transfer and readback work. Metal UI acceleration and interactive performance remain in development.

Use the maintainer's UniXNU and ArmCpu forks for the MT8167 storage, GICv2 and board integration. The device repository records the build revisions and root-authentication inputs.

## Maintenance

The maintainer owns the repositories and their release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.

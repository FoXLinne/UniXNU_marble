# Benesse TAB-A04-BR3（a04br3）

a04br3 是搭载联发科 MT8167 的 Benesse TAB-A04-BR3 平板，四核 Cortex-A35、GIC-400、2 GiB DRAM 和 eMMC。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 |
| --- | --- |
| [UniXNU-a04br3](https://github.com/mouseos/UniXNU-a04br3) | [mouseos](https://github.com/mouseos) |
| [uefi-a04br3](https://github.com/mouseos/uefi-a04br3) | [mouseos](https://github.com/mouseos) |
| [NativeMsdc](https://github.com/mouseos/NativeMsdc) | [mouseos](https://github.com/mouseos) |

## 当前状态

平板已在四个 CPU 上运行 iPadOS 主屏幕，eMMC DMA 和 CPU 帧缓冲渲染可用。PowerVR Vulkan 传输与读回可用，Metal 界面加速和交互性能仍在开发。

MT8167 存储、GICv2 和板级集成使用维护者的 UniXNU 与 ArmCpu 分支。设备仓库记录构建版本和根卷认证输入。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。

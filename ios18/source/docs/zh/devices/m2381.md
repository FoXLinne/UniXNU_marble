## 当前状态

`m2381` 分支在 `devices/m2381/unixnu-m2381/` 中维护设备树，并在 `devices/m2381/uefi/` 中维护固件集成。内核、预链接和负载仍在适配。

根据当前状态和 CI 记录选择 donor ABI 及匹配的负载输入，运行 CI 时使用记录中指定的设备分支。

## 使用此移植

1. 阅读下方固定版本的源码说明和验证记录，准备该设备要求的固件和系统输入。
2. 克隆设备仓库，在检出目录内按其构建指南准备依赖：

```sh
git clone --branch m2381 https://github.com/RiverKawa271828/ios-m2381-unixnu.git
cd ios-m2381-unixnu
git checkout 5886f365d16ab442c0f6210cfdf59ad9bb6a0ab0
git submodule update --init --recursive
```

3. 在该版本完成对应构建后，按[启动验证顺序](/zh/porting/bring-up)验证，并按[日志抓取](/zh/porting/log-capture)保存最后确认的阶段。
4. 将结果写入[移植记录](/zh/porting/records)。板级结构和组件选择见[移植设备](/zh/porting/steps)。

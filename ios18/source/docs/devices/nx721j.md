# ZTE Nubia Z60 Ultra (nx721j)

A community-maintained port for Pineapple. Current results are based on the maintainer records at the revisions linked below.

| --- | --- |
| [UniXNU-Nubia-Z60U](https://github.com/SangLuoCN/UniXNU-Nubia-Z60U) | [SangLuoCN](https://github.com/SangLuoCN) |

## State

The board selects the Pineapple platform and `nx721j_probe_defconfig`. The source includes a passive UFS probe and CI integration. Target firmware, payload inputs and device boot results remain to be completed.

## Use this port

1. Read the repository build instructions and pinned records. Prepare its firmware, system images and board inputs.
2. Build with that repository's commands. Use [Build and boot](/building) for common configuration.
3. Follow the [bring-up order](/porting/bring-up) and save results through [log capture](/porting/log-capture).
4. Update the [porting record](/porting/records) with the source revisions and last confirmed stage.

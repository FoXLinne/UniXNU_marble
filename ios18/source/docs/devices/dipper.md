# Xiaomi Mi 8 (dipper)

Xiaomi Mi 8 (dipper) is a SDM845 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-dipper](https://github.com/hanyaa380/UniXNU-dipper) | [hanyaa380](https://github.com/hanyaa380) |

## State

UEFI firmware, boot image, UniXNU menu, payload FAT and a synthetic DarwinBoot handoff work on hardware. The public fajita kernel reaches BSD init; it has no NativeUfs, so the root device wait never completes.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.

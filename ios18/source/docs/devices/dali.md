# Redmi K80 Ultra (dali)

Redmi K80 Ultra (dali) is a MT6991 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-Dali](https://github.com/localhosts-A/UniXNU-Dali) | [localhosts-A](https://github.com/localhosts-A) |
| [UEFI-Dali](https://github.com/localhosts-A/UEFI-Dali) | [localhosts-A](https://github.com/localhosts-A) |

## State

The current target is a single-core XNU early-boot checkpoint through UniXNU and DarwinBoot. Storage, root and iOS userland are outside this stage.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.

# Unisoc UMS512 / T610YP

Unisoc UMS512 / T610YP is a UMS512 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-t610yp](https://github.com/hxzbaka/UniXNU-t610yp) | [hxzbaka](https://github.com/hxzbaka) |

## State

First-boot device repository. It supplies the board description, source-kernel configuration and ADT generator; the UEFI side is the external `edk2-sprd` tree. No hardware result is documented.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.

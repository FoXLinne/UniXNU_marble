# NativeMsdc (community)

MediaTek MT8167 MSDC eMMC block driver for the Benesse TAB-A04-BR3. Publishes the root image windows and the persistent Data store.

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [NativeMsdc](https://github.com/mouseos/NativeMsdc) | [mouseos](https://github.com/mouseos) | MediaTek MT8167 MSDC eMMC block driver for the Benesse TAB-A04-BR3. Publishes the root image windows and the persistent Data store. |

## State

Compiles against xnu-10063.141.1 headers. The register sequences were used by the earlier a04br3 XNU port; the driver has not booted.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the driver and its state; it does not take over maintenance.

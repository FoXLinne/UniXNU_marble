# unixnu-nativefocaltechtouch

FT8203 touch controller support over Qualcomm GENI SPI for the Samsung Galaxy Tab S7 FE Wi-Fi (SM-T733).

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [unixnu-nativefocaltechtouch](https://github.com/RigoLigoRLC/unixnu-nativefocaltechtouch) | [RigoLigoRLC](https://github.com/RigoLigoRLC) | FT8203 touch controller support over Qualcomm GENI SPI for the Samsung Galaxy Tab S7 FE Wi-Fi (SM-T733). |

## State

The Tab S7 FE page records basic tap and swipe input; interrupt and suspend recovery are still in progress.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the driver and its state; it does not take over maintenance.

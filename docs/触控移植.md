# 触控移植

## marble 硬件

| 参数 | 值 |
| --- | --- |
| SoC | SM7475 |
| 触控控制器 | Goodix GT9916R |
| 面板 | 1080 × 2400 |
| 控制器坐标范围 | 10800 × 24000，十分之一像素 |
| SPI 控制器 | Qualcomm QUP GENI |
| Serial engine 地址 | 0x990000 |
| QUP wrapper 地址 | 0x9c0000 |
| GCC 地址 | 0x100000 |
| TLMM 映射地址 | 0x0f110000 |
| IRQ GPIO | 21，低电平触发事件读取 |
| Reset GPIO | 20 |
| 当前 SPI 时钟 | 1 MHz |
| DMA 缓冲区 | 连续物理内存 8192 字节，TX／RX 各 4096 字节 |
| Apps SMMU 地址 | 0x15000000 |
| QUP stream ID | 0x5a3 |
| DT context bank 上限 | 78 |
| DT stream group 上限 | 120，实际按硬件 ID 寄存器约束 |
| RPMh command DB | 0x80860000 |
| RPMh 控制器 | 0x17a20000，AP DRV2 |
| IOVDD | ldoc2，1800 mV |
| AVDD | ldoc9，3224 mV |

SPI 波形由 GENI 控制器生成，数据由 DMA 传输。软件轮询 IRQ GPIO 和传输状态。
IRQ 引脚处于空闲电平时休眠 8 ms；事件处理结束后休眠 1 ms。

## Goodix 数据路径

`MarbleTouch.cpp` 包含供电、GPIO 复位、GENI 初始化和 `geni_spi_set_clock`。
读取命令为 0xf1，随后为大端 32 位地址，接收数据从第 8 字节开始；写入命令为 0xf0，随后为大端地址与数据。

控制器确认值为 0xaaaaaaaa，产品标识为 9916R。事件地址从 IC info 解析；marble 实测为 0x10308。
事件头为 8 字节，触点记录为 8 字节；读取 26 字节前缀，根据触点数量扩展读取。
事件头校验成功后解析触点，向事件地址写入零值确认，再进入 HID 工作循环。

## XNU 接口

| 接口 | 用途 |
| --- | --- |
| `native_hid_touch_allocate()` | 创建触控 HID 设备 |
| `native_marble_touch_start()` | 启动触控读取线程 |
| `native_touch_publish(count, points)` | Goodix 数据提交到 HID |
| `native_marble_touch_report(out, size)` | 读取阶段、事件和校验计数 |
| `native_hid_request_tap(x, y)` | 注入测试点击，像素坐标 |
| `native_hid_request_contact(x, y, active)` | 注入接触或抬起，像素坐标 |

物理触控的入口为 `native_touch_publish`；注入点击接口供测试使用。
当前转发取首个触点，换算到像素坐标后提交接触状态。HID 逻辑坐标为 0 到 32767。
边缘手势在接触起点距离屏幕边缘 48 像素内时设置 `kIOHIDDigitizerEventFromEdgeTip`。

## 接入条件

将 `GeniSpi.c` 作为 C 源码编译，`MarbleTouch.cpp` 与 `NativeHomeInput.cpp` 作为内核 C++ 源码编译。
包含路径加入 `spi`、`hid` 以及目标 XNU 内核 SDK。

`integration/HidHomeProbe.cpp` 保留原工程初始化顺序：加载 IOHIDFamily／IOHIDEventDriver、等待 IOHIDResource、注册 metaclass、创建 HID 设备、启动触控线程。
原调用点通过 `offline-hid-home=1 marble-touch=1` 启用触控；`marble-touch=2` 创建 HID 设备后等待外部启动请求。
该文件还包含原工程的 Home 注入及 GPU 启动引用，移植方需按自身入口接入触控调用。

`NativeHomeInput.cpp` 引用三个宿主接口：`native_hid_input_observed`、`native_hid_live_checkpoint` 和 `native_hid_input_requested`；原定义见 `HidHomeProbe.cpp`。
`HidHomeProbe.cpp` 另外引用原工程的 `native_legacy_transfer_calls`、`native_marble_gpu_start` 和 `g_kernel_kmod_info`。

`OriginalHidDeviceABI.h` 对应 21H461 的 IOHIDDevice，类大小为 208 字节。
边缘标记依赖 IOHIDEventDriver／IOHIDEvent 的虚函数槽位。
使用其他 iOS 版本时需核对类布局、虚函数槽位、HID 匹配条件和内核链接符号。

## sweet 接入项

| 可复用内容 | 需按目标设备核对的内容 |
| --- | --- |
| GENI SPI 寄存器访问与 DMA 传输 | QUP serial engine、时钟源、GPIO 功能配置 |
| SMMU stream 配置方法 | SMMU 地址、stream ID、bank 与 stream group 数量 |
| Goodix 读写与校验流程 | 触控芯片型号、协议、IC info 与事件格式 |
| HID 报告与坐标换算 | 面板尺寸、坐标单位、屏幕方向、OS ABI |
| RPMh command DB 查询与投票方式 | 电源资源名称、电压、DRV／TCS 所有权 |

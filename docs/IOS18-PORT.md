# marble iOS 18.7.11 移植

系统版本为 22H384。分支起点为 `7a0d68ff`，iOS 27 实现参照 `780d3b2d`。候选与产物摘要见 [CURRENT.json](../CURRENT.json)。本页记录每个阶段的来源和实际结果。

| 阶段 | 实现来源与结果 |

| USB、内核日志和复位 | R1 在 MPIDR `0x100` 保持 RootStage，panic 后读出 XNU 日志并经固件命令返回 Fastboot。R2 在 DarwinBoot 末段启动驻留核心时触发固件异常。R3 保留 22H384 的 USB 交接时机和 watchdog，通过 USB 读取 IOKit panic 并回到 Fastboot。R4 在用户态可读内核日志和控制触控。R5 经 Mac 发起的单设备 USB 总线复位恢复连接，耗时 9.313 秒。物理拔插和服务停滞恢复待覆盖。R33 使用内核 USB 配置临时启动，Mac 识别为 iPhone，lockdownd 返回 `iPhone16,2` 和 `22H384`。R33 无锁屏密码候选成功配对，配对会话返回 `PasswordProtected=false`。断开事件恢复候选增加一次控制器重启机会，宿主测试覆盖重复事件、取消重试和计数器回绕。构建记录见 [CURRENT.json](../CURRENT.json)。 |
